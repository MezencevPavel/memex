# Memex

**Memex** — личная база знаний: заметки, глоссарий, сниппеты, ссылки, контакты. Однопользовательское веб-приложение на Flask + SQLite.

Название — отсылка к концепции Ванневара Буша (1945): «устройство для расширения памяти».

Версия: `v1.0.0`

---

## Возможности

### Заметки
- Хранение в Markdown с живым предпросмотром при редактировании
- Дерево категорий неограниченной вложенности
- Даты создания и изменения, сортировка
- Ссылки между заметками через `[[Название]]`
- Избранное (закреплённые заметки)
- Импорт и экспорт `.md`
- Загрузка картинок с автоматическим сжатием в WebP

### Глоссарий
- Термины с определениями в Markdown
- Группировка по темам
- Всплывающие подсказки в заметках через `{{термин}}`
- Поиск, импорт и экспорт в JSON / Markdown / CSV

### Сниппеты
- Короткие команды с копированием в один клик
- Группировка по темам
- Быстрый доступ из правой панели заметки

### Ссылки
- Полезные URL с описанием
- Копирование в один клик

### Контакты
- Справочник номеров с описанием
- Копирование номера в один клик

## Стек

| Слой | Технология |
|---|---|
| Язык | Python 3.9+ |
| Веб-фреймворк | Flask |
| ORM | Flask-SQLAlchemy |
| Аутентификация | Flask-Login + Werkzeug |
| База данных | SQLite |
| WSGI | Gunicorn |
| Reverse proxy | Nginx |
| Markdown (сервер) | Python-Markdown |
| Markdown (клиент) | marked.js |
| CSS | Bootstrap 5 |
| Изображения | Pillow (WebP) |

---

## Структура

- `app.py` — всё приложение
- `requirements.txt` — Python-зависимости
- `README.md` — этот файл
- `PROJECT.md` — полная документация
- `ansible/` — автоматическое развёртывание
- `static/img/` — логотип
- `static/js/` — клиентские скрипты
- `templates/` — Jinja2-шаблоны

---

## Что не хранится в репозитории

- `venv/` — виртуальное окружение
- `instance/` — база данных SQLite
- `static/uploads/` — загруженные картинки
- `ansible/inventory.ini` — реальные IP и пути
- `.env` — секреты
- `backups/` — резервные копии

## Документация

Развёртывание, эксплуатация, тонкости реализации — в файле `PROJECT.md`.
